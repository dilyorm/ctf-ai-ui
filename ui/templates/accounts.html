Account Pool

Shared, team-wide pool of subscription accounts. Every account here is used by all runs. When one hits its limit, solvers automatically rotate to the next available account. Add as many as you like.

Claude, Codex, Grok sign in with your subscription via their CLI — click, open the link, approve, done. Each account gets its own isolated config dir, so add as many as you like and the pool rotates + switches between them. Copilot uses GitHub device login. Kimi has no headless CLI login, and Antigravity stores creds in the OS keyring (can't be pooled) — so both connect with a subscription token (Kimi Code key / Gemini key), verified live.
